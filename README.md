# 友安製作所LPサイト制作

LPサイトを作る

## コーディングルール

原則issuesベースで開発する

ブランチの名前は以下の通りに設定すること

1. githubのissuesを作成する
2. 作成したissuesの番号を確認 (#4みたいなやつ)
3. 確認した番号が4として feature/#4 みたいな名前でブランチを切る(ブランチを切る時は最新状態のdevelopをソースとすること)

### gitルール

- main,developは直接触らないこと
- 各ブランチでの作業が終了したら、developに一度pushすること
- コーディングリーダーがコードを確認し、OKならmergeする(リーダー以外mergeしないこと)

### コミットルール

- commitする際はそれぞれの要件に合わせて以下のように設定すること。

" ??? : 〇〇 "

???の部分はそれぞれ以下のルールに乗っ取り設定すること

style：cssのみの変更の際に使用。
feat：ロジックに関わるコードを編集した際に使用
fix：バグ修正の際に使用
docs：document編集時に使用
refactor：コードのリファクタリングを行った際に使用

尚今回commitlintを実装予定なので、以下のルール以外でのcommitは弾かれるので、気をつけてください
